# User Flow

## Main Flow

Login
→ Emotion Assessment
→ AI Analysis
→ Personalized Recommendation
→ Start Learning
→ AI-generated Content
→ Learning Record
→ Adaptive Adjustment
→ Continue Learning

---

## Emotion Assessment Flow

User enters assessment
→ Answer emotional questions
→ AI analyzes emotional state
→ Generate emotional profile
→ Recommend suitable learning content

---

## Adaptive Learning Flow

System tracks:
- learning time
- completion rate
- emotional changes

AI dynamically adjusts:
- course difficulty
- recommendation order
- interaction style
