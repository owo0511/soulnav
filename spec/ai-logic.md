# AI Logic

## AI Inputs
- Emotion assessment result
- Learning progress
- User behavior
- Completion rate
- Learning history

---

## Emotion Analysis
The system analyzes the user's emotional condition and determines the current emotional state.

Possible states:
- Stress
- Anxiety
- Motivation loss
- Stable

---

## Recommendation Logic

If:
- stress level is high
- completion rate is low

Then:
- recommend shorter lessons
- reduce quiz difficulty
- provide encouragement content

If:
- learning performance is stable

Then:
- recommend advanced content
- increase interaction tasks

---

## Topic Recommendation Logic

The AI system recommends different learning topics based on emotional analysis.

Examples:

- High exam anxiety
→ Emotional Regulation Skills

- High academic pressure
→ Stress Coping Strategies

- Social fear during presentations
→ Social Anxiety Management

- Frequent procrastination behavior
→ Procrastination Behavior Restructuring

---

## Interactive Activity Logic

The AI system dynamically selects interactive learning activities based on:

- emotional state
- learning behavior
- stress level
- learning progress

Examples:

- High anxiety
→ breathing exercises

- Social fear
→ communication simulation

- Low motivation
→ short interactive challenges

- Severe procrastination
→ habit rebuilding activities

---

## Adaptive Learning Logic

The system dynamically adjusts:
- course order
- learning difficulty
- quiz amount
- interaction style

based on user learning behavior.

---

## Challenge Adjustment Logic

The AI system dynamically adjusts challenge duration and task pressure based on user emotional and behavioral analysis.

Adjustment factors:
- emotional state
- stress level
- available study time
- completion rate
- learning habits

Examples:

- High stress level
→ extend challenge duration
→ reduce task pressure

- Late-night usage
→ avoid short deadlines
→ provide flexible completion periods

- Stable learning behavior
→ increase challenge difficulty
→ shorten challenge duration

---

## AI Outputs
- Personalized courses
- AI-generated quizzes
- Emotional suggestions
- Learning path adjustments
