# Frontend Specification

## UI Style
Design Direction:
- friendly
- relaxing
- low-pressure
- emotionally supportive
- mobile-first design

Target Users:
- high school students

Primary Device:
- smartphone

Visual Style:
- soft color palette
- card-based layout
- rounded UI components
- emotional illustrations
- clean navigation structure
- touch-friendly interaction

Design Principles:
- simple navigation
- short interaction flow
- minimal text overload
- easy one-hand operation
- responsive mobile layout

## Navigation Structure
Mobile Navigation:
- Dashboard
- Learning Topics
- Challenges
- Progress
- Profile

Navigation Style:
- bottom navigation bar
- touch-friendly buttons
- minimal navigation depth

## Dashboard
Purpose:
Display emotional status, AI recommendations, learning progress, and active challenges.

Components:
- emotional summary
- AI recommended topics
- active adaptive challenges
- learning progress overview
- quick access buttons
- daily emotional insights

Features:
- personalized recommendations
- dynamic challenge updates
- emotional trend visualization

## Emotion Assessment Page
Purpose:
Analyze the user's emotional condition before learning.

Components:
- emotional questions
- emoji selection
- stress scale
- progress indicator
- submit button

Features:
- AI emotional analysis
- emotional state classification
- personalized recommendation generation

## Learning Topic Page
Purpose:
Display personalized learning topics recommended by the AI system.

Components:
- topic cards
- emotional tags
- recommendation reason
- difficulty indicator
- progress tracking

Features:
- AI-generated learning content
- dynamic topic recommendation
- adaptive learning sequence

## Interactive Activity Page
Purpose:
Provide interactive emotional and behavioral training activities.

Components:
- breathing exercises
- scenario interactions
- self-reflection questions
- interactive quizzes
- AI conversation module

Features:
- dynamically selected activities
- emotional interaction support
- personalized interaction flow

## Adaptive Challenge Page
Purpose:
Provide flexible behavioral challenges adjusted by the AI system.

Components:
- active challenges
- challenge timer
- completion tracking
- progress feedback
- motivational messages

Features:
- adaptive challenge duration
- dynamic task difficulty
- behavioral adjustment support
- personalized challenge generation

## User Progress Dashboard
Purpose:
Track emotional improvement and learning progress.

Components:
- emotional trend chart
- challenge completion history
- learning statistics
- achievement badges
- AI progress insights

Features:
- emotional tracking visualization
- behavioral analysis
- adaptive learning analytics
