# SoulNav Product Spec

## System Overview
SoulNav is an AI-powered adaptive learning management system focused on emotional and behavioral adjustment for high school students.

The system dynamically generates learning content and adjusts learning paths based on user emotional state and learning behavior.

---

## Target Users
- High school students
- Students with emotional stress
- Users needing personalized learning guidance

---

## Core Features
- Emotion assessment
- AI-generated learning content
- Adaptive learning path
- Personalized recommendation
- Emotion tracking
- Learning analytics

---

## Learning Topics

The system currently focuses on four main emotional learning topics:

1. Emotional Regulation Skills
- Exam anxiety
- Emotional recovery
- Self-awareness

2. Stress Coping Strategies
- Academic pressure
- Performance anxiety
- Mental stress management

3. Social Anxiety Management
- Presentation anxiety
- Group discussion pressure
- Communication confidence

4. Procrastination Behavior Restructuring
- Mobile phone addiction
- Homework procrastination
- Habit rebuilding

---

## Interactive Learning Activities

The system includes interactive learning activities designed to improve emotional awareness and behavioral adjustment.

Examples:
- Breathing exercises
- Emotional reflection activities
- Scenario-based choices
- AI interactive conversations
- Self-awareness quizzes
- Habit rebuilding challenges
- Presentation simulation training

The activities are dynamically recommended based on the user's emotional state and learning behavior.

---

## Adaptive Challenge System

The system provides flexible behavioral challenges with dynamically adjusted completion periods.

Instead of fixed daily tasks, the AI system adjusts:
- challenge duration
- task difficulty
- interaction frequency
- learning pressure

based on:
- emotional condition
- stress level
- learning behavior
- available learning time

Examples:
- short-term challenges
- multi-day behavioral missions
- habit rebuilding tasks
- emotional training activities

---

## AI Features
The AI system analyzes:
- emotional state
- learning progress
- user behavior
- completion rate

Then dynamically:
- recommends learning content
- adjusts learning paths
- generates quizzes
- provides behavioral suggestions

---

## System Goals
- Reduce learning pressure
- Improve emotional awareness
- Increase learning engagement
- Provide personalized learning experiences

---

## User Flow
Login
→ Emotion assessment
